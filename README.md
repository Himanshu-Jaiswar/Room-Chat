# Room Chat Application

Real-time chat application with room support using Socket.io

## Features
- Join rooms
- Real-time messaging
- Multiple users

## Tech stack
Frontend:
- HTML
- CSS
- Reactjs

Backend:
- Node.js
- Express
- Socket.io

## Run locally
backend:
npm install
npm start

live:
https://onlineroomchat.netlify.app/
